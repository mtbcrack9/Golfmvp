# GolfMVP WHS v2

Neu:
- Brutto-/Netto-Score je Loch
- Handicap-Schläge nach Stroke Index
- Stableford-Punkte je Loch
- Brutto-, Netto- und Stableford-Gesamtsumme
- Course-Handicap-Berechnung
- Score-Differential-Berechnung als Rundenwert
- lokale Speicherung der Runden
- keine Schätzung offizieller Ratingdaten

Hinweis: Für eine offizielle Handicap-Führung müssen die Rating-/WHS-Daten aus einer autorisierten Quelle kommen. Die App berechnet die Werte aus den eingegebenen/verifizierten Platzdaten.
